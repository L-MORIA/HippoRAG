# Индекс-фикстура (H1-5)

Здесь лежит **урезанный снимок индекса** — чанки, их метаданные и манифест с
sha256. Он нужен, чтобы CI мог гонять **лексический** retrieval (BM25) без
эмбеддинг-модели, без LLM и без сети: полный индекс в репозитории не лежит
(и не должен), а смоук по фикстуре — воспроизводимая часть H1-5.

## Две фикстуры, и они разные

| Каталог | Что внутри | В git | В CI | Публиковать текст |
|---|---|---|---|---|
| `synthetic_mini/` | демонстрационные тексты из `scripts/make_synthetic_fixture.py` | ✅ да | ✅ обязательный шаг | нечего публиковать |
| `astrology_mini/` | срез реального индекса: **дословный текст книг корпуса** | ⛔ нет | ▶️ если закоммитят | ⛔ никогда |

Репозиторий публичный, поэтому по умолчанию работает **синтетическая**
фикстура: она проверяет механику (контракт, sha256, BM25, выбор документа), не
публикуя ни строки из книг.

## Синтетическая фикстура

```bash
# пересобрать (менять тексты и разметку — в скрипте, не в JSON)
python scripts/make_synthetic_fixture.py

# проверить, что закоммиченные файлы совпадают со сборкой из кода
python scripts/make_synthetic_fixture.py --check
```

В каталоге:

* `fixture.json` — 24 чанка из трёх демонстрационных «документов»
  (`demo_minerals.pdf`, `demo_crafts.pdf`, `demo_climate.pdf`);
* `manifest.json` — версия формата, время создания, число чанков, sha256;
* `questions.jsonl` — 10 вопросов в формате `eval/dataset/questions.jsonl`,
  каждый целится в свой чанк редкими словами.

Сборка детерминирована (фиксированный `created_at`, LF-переводы строк), поэтому
`--check` — честный gate: если правку внесли руками в JSON, а не в скрипт,
файлы разъедутся и CI покраснеет.

Локальный прогон:

```bash
python scripts/index_fixture_smoke.py \
    --fixture fixtures/synthetic_mini \
    --dataset fixtures/synthetic_mini/questions.jsonl \
    --limit 0 \
    --top-k 5 \
    --min-recall 0.9
```

## Фикстура владельца (опционально)

Нужна только если хочется ловить регрессию BM25 на **реальном** корпусе.

```bash
# на машине владельца, где есть собранный индекс
python scripts/build_index_fixture.py \
    --index outputs/astrology_test \
    --out fixtures/astrology_mini \
    --max-chunks 300
```

⚠ Фикстура — это дословный текст чанков ваших документов (~535 КБ на 300
чанков). В публичном репозитории её быть не должно. Если всё же коммитите —
осознайте, что текст становится публичным; джоб `Index Fixture Smoke` подхватит
каталог автоматически и прогонит по нему отдельный шаг.

## Что публикуется

Только отчёты `outputs/reports/fixture_smoke.{json,md}` — там нет текста
чанков, только `qid`, ожидаемый файл, позиция и признак попадания. Сам каталог
фикстуры в артефакт не выкладывается ни в каком варианте.

## Проверка контракта

* `tests/unit/test_index_fixture_contract.py` — формат, манифест, подмена,
  BM25, коды возврата скриптов (на синтетических чанках в tempdir);
* `tests/unit/test_synthetic_fixture_ci.py` — закоммиченная фикстура цела,
  совпадает со скриптом и проходит порог recall.
