# Индекс-фикстура (H1-5)

Здесь владелец кладёт **урезанный снимок индекса** — чанки, их метаданные и
манифест с sha256. Он нужен, чтобы CI мог гонять **лексический** retrieval
(BM25) без эмбеддинг-модели, без LLM и без сети: полный индекс в репозитории
не лежит (и не должен), а смоук по фикстуре — воспроизводимая часть H1-5.

## Что это даёт и что не даёт

| | Полный retrieval (эмбеддинги) | Лексический смоук (BM25) |
|---|---|---|
| Нужна эмбеддинг-модель | да | нет |
| Нужен LLM | для режимов-ответов | нет |
| Нужен индекс | полный | урезанный |
| Где запускается | локально у владельца | в CI |

Полный retrieval с эмбеддингами в CI не воспроизводится — это осознанное
ограничение, а не недоработка: эмбеддинг-модель весит сотни мегабайт, а
индекс — это данные владельца.

## Как собрать

```bash
# на машине владельца, где есть собранный индекс
python scripts/build_index_fixture.py \
    --index outputs/astrology_test \
    --out fixtures/astrology_mini \
    --max-chunks 300
```

В каталоге появятся:

* `fixture.json` — чанки (`hash_id`, `content`, `metadata`) и метаинформация;
* `manifest.json` — версия формата, время создания, число чанков и sha256
  каждого файла.

После этого закоммитьте `fixtures/astrology_mini/` в репозиторий: джоб
`Index Fixture Smoke` в `.github/workflows/ci-cd.yml` сам подхватит фикстуру,
прогонит смоук на 10 вопросах и выложит **фикстуру и отчёт** артефактом прогона.

## Проверка локально

```bash
python scripts/index_fixture_smoke.py \
    --fixture fixtures/astrology_mini \
    --limit 10 \
    --top-k 5 \
    --out outputs/reports/fixture_smoke.json \
    --markdown-out outputs/reports/fixture_smoke.md
```

Контракт формата проверяется тестом: `tests/unit/test_index_fixture_contract.py`.

## ⚠ Фикстура содержит текст корпуса

Фикстура — это дословный текст чанков ваших документов. Если выкладываете её
как артефакт публичного прогона, текст становится доступен всем, кто видит
артефакты. Если это нежелательно — не коммитьте фикстуру, а в артефакт
выкладывайте только отчёт смоука (для этого удалите каталог фикстуры из
репозитория: джоб отработает в режиме «фикстуры нет»).
