# Руководство пользователя HippoRAG

> **Кому:** человеку, который хочет задавать вопросы по корпусу астрологических
> PDF и получать ответы со ссылками на источники.
>
> **Что уже готово:** CLI (`python main.py`) и веб-интерфейс (H2-1).
> Администрирование — в [ADMIN_GUIDE.md](./ADMIN_GUIDE.md), устройство системы —
> в [ARCHITECTURE.md](./ARCHITECTURE.md), типовые ошибки — в
> [TROUBLESHOOTING.md](./TROUBLESHOOTING.md).

## 1. Что нужно

- **Python 3.10–3.12** (3.13+ не поддерживается).
- **LM Studio** с одной из моделей, например `google/gemma-4-e4b`.
- **8+ ГБ RAM**. Все методы работают на CPU; CUDA не обязательна.
- PDF-корпус. В репозитории его нет: положите свои файлы в `data/pdfs/`.
- Для режима 5 при первом запуске скачивается русский cross-encoder
  `DiTy/cross-encoder-russian-msmarco` (~700 МБ).

## 2. Установка

Самый простой способ (H2-3):

- Windows: `start.bat`;
- Linux/macOS: `./start.sh`;
- Docker: `docker compose up --build`.

Скрипт создаст `.venv`, установит зависимости, скопирует `.env.example` в
`.env` (если файла нет), проверит LM Studio и запустит UI. Приёмка на чистой
машине ещё не проводилась; чек-лист —
[H2_3_PACKAGING_2026-11-06.md](./H2_3_PACKAGING_2026-11-06.md).

Ручная установка:

```bash
git clone https://github.com/L-MORIA/HippoRAG.git
cd HippoRAG
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

Linux/macOS:

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

Проверка:

```bash
python -c "import main; print('ok')"
```

## 3. Настройка

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
LLM_NAME=gemma-4-e4b
LLM_API_NAME=google/gemma-4-e4b
LLM_BASE_URL=http://localhost:1234/v1
SAVE_DIR=outputs/astrology_test
```

- `LLM_NAME` — имя каталога индекса и кэша.
- `LLM_API_NAME` — id модели в LM Studio. Нужен, если он отличается от имени
  каталога; иначе LM Studio вернёт `400 Invalid model identifier`.
- `SAVE_DIR` — каталог индекса. Он должен совпадать при индексации и при поиске.

Запустите LM Studio: **Developer → Start Server**, порт `1234`. Проверка:

```bash
curl http://localhost:1234/v1/models
```

## 4. Индекс

Положите PDF в `data/pdfs/` (поиск рекурсивный) и соберите индекс:

```bash
python index_pdfs.py --pdf_dir data/pdfs --output_dir outputs/astrology_test
```

Если в `.env` указан другой `SAVE_DIR`, используйте его и здесь. Проверка:

```bash
python scripts/show_index_stats.py --save_dir outputs/astrology_test
```

Подробности — в [INDEXING_GUIDE.md](./INDEXING_GUIDE.md). Без индекса
интерфейс откроется, но на вопрос вернёт честный отказ.

## 5. Запуск веб-интерфейса

Самый простой способ — `start.bat` (Windows) или `./start.sh` (Linux/macOS):
скрипт сам создаст окружение и проверит LM Studio. Docker-вариант:
`docker compose up --build`; LM Studio при этом остаётся на хосте.

Ручной запуск:

```powershell
$env:PYTHONIOENCODING = "utf-8"
$env:API_KEY = "your-secret-key"
uvicorn astro_app.web:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/` и введите ключ в диалоге.

Для локального запуска без ключа (только loopback):

```powershell
$env:API_KEY_REQUIRED = "0"
uvicorn astro_app.web:app --host 127.0.0.1 --port 8000
```

Статика `/` и `/ui/*` открывается без ключа, а `/api/ask`,
`/api/feedback`, `/search` и `/health` защищены заголовком `X-API-Key`.
Ключ хранится в `sessionStorage` только на время вкладки.

> **Важно:** UI генерирует ответ через LLM для любого режима, включая
> «Быстрый». Если LM Studio недоступен, поиск может найти фрагменты, но
> ответом будет отказ с диагностикой `llm_unavailable_or_empty`.

## 6. Работа в веб-интерфейсе

### 6.1. Режимы

| Режим | Название | Когда выбирать | LLM для поиска |
|---|---|---|---|
| `5` | **Быстрый** (по умолчанию) | обычный поиск по книгам | нет |
| `2` | **Граф** (экспертный) | нужны связи между понятиями | нет |
| `1` | **Максимальный охват** (экспертный) | нужен более широкий поиск | да |

Экспертные режимы скрыты под вкладкой «Экспертные». Режим 5 в UI — **page-level**
путь H1-6: единица выдачи — страница, а не чанк. На golden set M7 page recall@5
**87,0 %**, на 40 вопросах H1-1 — 80,0 %. Чанковый baseline H2-6 возвращается
переменной `ASTRO_RETRIEVER_PAGE_LEVEL=0`.

### 6.2. Ответ

- В тексте ответа стоят ссылки `[n]` на фрагменты.
- Под ответом — **только использованные** цитаты: документ, страница, раздел,
  короткий фрагмент текста.
- Ниже можно раскрыть найденные фрагменты — это диагностика поиска, а не
  доказательство ответа.
- Если ответа нет в источниках, система пишет общий отказ. Это нормальное
  поведение, а не ошибка.
- Бейдж заземления: `0 %` — отказ или нет цитат, `50 %` — есть замечания,
  `100 %` — чистое заземление. Это **не вероятность правильности ответа**.

Кнопка «Скопировать» копирует текст ответа. Ссылки `[n]` кликабельны и
прокручивают к соответствующей цитате.

### 6.3. Обратная связь

Под ответом есть кнопки «Полезно» и «Бесполезно». Можно добавить комментарий
и отправить оценку. Запись попадает в append-only JSONL:

```text
outputs/feedback/feedback.jsonl
```

Путь переопределяется переменной `FEEDBACK_PATH`. Сохраняются вопрос, ответ,
режим, оценка, комментарий и цитаты. IP, user-agent и ID пользователя **не
сохраняются**.

### 6.4. История

История хранится **только в браузере** (`localStorage`, до 50 записей).
Сервер её не получает. Кнопка записи восстанавливает прошлый ответ; очистка
истории удаляет записи в текущем браузере. В другом браузере или после
очистки данных сайта история будет пустой.

### 6.5. Экспорт

- текущий ответ — Markdown или JSON;
- вся история — Markdown или JSON.

Экспорт выполняется на клиенте и не делает дополнительных запросов к серверу.
В Markdown попадают вопрос, режим, дата, оценка заземления, ответ и цитаты.

## 7. CLI

```bash
python main.py
```

1. Выберите модель (Enter — текущая из `.env`).
2. Дождитесь загрузки индекса.
3. Выберите режим: **5 «BM25+CE-ru»** по умолчанию, рекомендованы также
   **2 «Граф»** и **22 «Pattern Search»**.
4. Введите вопрос.

Генеративные режимы 12, 19 и 21 отвечают по контракту:

```text
ОТВЕТ: Овну соответствуют прихожая и плита [1]. Управитель — Марс [1].
ИСТОЧНИКИ: 1
ОТКАЗ: нет
```

Если ответа нет во фрагментах, модель возвращает общий отказ. Ответ без
валидных ссылок `[n]` заменяется отказом; допускается один repair-retry.

QA Cache автоматически сохраняет ответы в `outputs/qa_cache/qa_cache.json`.
Пункт `t` в меню тестирует методы и сравнивает с кэшем, `e` экспортирует
JSONL для fine-tuning.

## 8. Приватность и ограничения

- Корпус и индекс остаются локальными; запросы к LLM идут на ваш
  `LLM_BASE_URL` (по умолчанию LM Studio на loopback).
- Обратная связь и история не содержат персональных данных.
- Один общий `API_KEY`; нет пользователей, ролей и rate limiting.
- Нет добавления/удаления PDF через UI — это задача H2-2. Пока используйте
  `index_pdfs.py`.
- Docker и one-command start реализованы в H2-3; приёмка на чистой машине
  ещё не проводилась.
- Нет дашборда метрик — это H2-4.
