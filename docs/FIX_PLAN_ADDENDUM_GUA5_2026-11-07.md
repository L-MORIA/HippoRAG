**Автор:** диагностическое расследование ZCode + справка автора книг

## 1. Согласие и независимое подтверждение §1a

Правка §1a в `MANUAL_TEST_BACKEND_FINDINGS_2026-11-07.md` подтверждена
независимо (спот-чек чанка 1115, стр. 25: «Мужчина-пятёрка опирается на
знания (северо-восток), а женщина-пятёрка — на сотрудничество (югозапад)» —
цитата подлинная). Факт в корпусе есть, вопрос «гуа 5» — **answerable**.

Дополнительные замеры, которых нет в §1a (важны для выбора исправления):

1. **Промах ретрива измерен.** Продуктовый page-level поиск (режим 5) на
   запрос «Какое направление Шен-ци у числа гуа 5?»: страницы с ответом
   **55, 58, 62, 65 не попадают в топ-20**; топ-5 = стр. 27, 73, 80, 148, 114.
   Стр. 73 (ранг 2) даёт направление образования для женщин-«пятёрок», но
   промптом помечено «для образования» — заземление консервативно отказывает.
2. **Причина — лексический разрыв.** Запрос содержит «шен-ци»; страницы
   55/58/62/65 написаны через «лучше направление здоровья», «романтическое
   направление» — без слова «шен-ци». В `synonyms.json` (66 ключей) связки
   «шен-ци ↔ лучшее направление» **нет** — query expansion мост не строит.

## 2. Правки в план (до реализации)

### F-10 — переписать

**Сейчас:** «"гуа 5" добавлен в unanswerable-секцию golden set (факт
отсутствует — это корректный отказ)».
**Проблема:** факт в корпусе есть (стр. 25, 29, 55, 58, 62, 65, 73, 99–101,
111, 120) — такая разметка закрепит ошибку как эталон.
**Должно быть:** «гуа 5» — кандидат в **answerable**-секцию: gold-ответ
«мужчина-пятёрка — северо-восток (как гуа 2), женщина-пятёрка — юго-запад
(как гуа 8)», gold-страницы 25, 29, 55, 58, 62, 65, 73, 99–101, 111, 120.
В unanswerable не добавлять.

### F-9 — переписать целевой ответ

**Сейчас:** система должна отвечать «собственного направления Шен-ци у числа
гуа 5 в книгах нет; …» — это **фактически неверный ответ**: собственные
направления в книге есть (СВ/ЮЗ по полу + тематическая сетка по десяти
аспектам).
**Должно быть:** ответ по существу — «мужчине-пятёрке — северо-восток
(знания, как гуа 2), женщине-пятёрке — юго-запад (сотрудничество, как
гуа 8)» с цитатами стр. 25/29/99–101; фраза «по схеме „гуа N (… шен-ци…)»
пятый номер в таблицах не фигурирует» допустима как оговорка, не как основа
ответа.

### Новая задача (предлагаю F-13) — мост синонимов

`src/astro_app/data/synonyms.json`: добавить связку
«шен-ци → лучшее направление, направление здоровья, романтическое
направление» (и проверить обратную сторону: «лучшее направление → шен-ци»).
После правки — контроль: страницы 55/58/62/65 входят в топ-5 продуктового
поиска на вопрос владельца. Без этой задачи retrieval-промах останется даже
после F-9/F-10: модель не увидит страницы с ответом.
