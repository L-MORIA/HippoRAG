# Уточнение автора книг: число гуа 5 (2026-11-07)

**Источник:** владелец проекта, лично от автора книг (сообщение 2026-11-07).
Автор внесёт это в **следующее издание** «Эзотерического фэншуя» — до его
выхода данный документ является первоисточником уточнения для проекта.

## Формулировка автора

Разделение гуа на мужские и женские характерно **только для числа гуа 5**.

- **Мужчины с числом гуа 5** — их лучшие направления (шен-ци) соответствуют
  направлениям людей **с числом гуа 2 → северо-восток**.
- **Женщины с числом гуа 5** — их лучшие направления (шен-ци) соответствуют
  направлениям людей **с числом гуа 8 → юго-запад**.
- У самих чисел гуа 2 и гуа 8 **разделения на мужчин и женщин нет** —
  направление одно для всех.
- Разделение «мужское/женское» характерно только для людей с числом гуа 5.

## Согласование с текстом книги (нынешнее издание)

Уточнение автора согласуется с распределёнными формулировками корпуса
(см. `MANUAL_TEST_BACKEND_FINDINGS_2026-11-07.md` §1a):

- стр. 25: «Мужчина-пятёрка опирается на знания (**северо-восток**), а
  женщина-пятёрка — на сотрудничество (**югозапад**)» — СВ = шен-ци гуа 2,
  ЮЗ = шен-ци гуа 8 (стр. 29, 111);
- Резюме, стр. 99–101: «„ПЯТЁРКАМ“-МУЖЧИНАМ … (центр, северо-восток)»,
  «„ПЯТЁРКАМ“-ЖЕНЩИНАМ И „ВОСЬМЁРКАМ“ … (центр, юго-запад)»;
- тематическая сетка по десяти аспектам (стр. 55–96): мужчины-«пятёрки»
  всегда в паре с гуа 2, женщины-«пятёрки» — с гуа 8.
