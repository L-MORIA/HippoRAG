## 1. Зачем

До H2-1 у проекта был CLI и защищённый `/search`, но не было одного входа,
которым может воспользоваться человек без знания режимов и API. H2-1 добавляет
браузерный интерфейс поверх существующего FastAPI-приложения:

- один вопрос — один ответ с цитатами;
- ровно три проверенных режима: default + два экспертных;
- явный отказ вместо ответа без источников;
- обратная связь «полезно / бесполезно»;
- история запросов и экспорт ответа.

UI не создаёт второе приложение и не дублирует поиск: он вызывает те же
функции реестра `astro_app.modes`, что и CLI, и тот же контракт заземления
`answer_grounded` (H2-6).

## 3. Режимы

| id | Название | Экспертный | Что делает | Ориентир latency |
|---|---|---:|---|---|
| `5` | Быстрый | нет | BM25 + русский cross-encoder, обычный поиск по книгам | ~0,2 с |
| `2` | Граф | да | Entity linking + PPR по графу знаний | ~0,7 с |
| `1` | Максимальный охват | да | Multi-vector + переформулировка запроса через LLM | ~6–13 с |

Это ровно те режимы, которые уже измерены в H1-3; UI не обещает
невыверенную скорость. Режим по умолчанию берётся из реестра
(`DEFAULT_MODE`), а не дублируется в браузере.

> **Важно:** режим 5 в UI — измеренный **чанковый** путь CLI
> (`search_bm25_hybrid_ru`). Новый page-level путь H1-6 пока не подключён к UI:
> сначала нужно снять page recall@5 и перезамерить H2-6.

## 4. Контракт ответа

`POST /api/ask` принимает `{question, mode, top_k}` и возвращает:

- `answer` — текст с inline-ссылками `[n]` или общий отказ `ABSTAIN_TEXT`;
- `citations` — **только использованные** цитаты: `doc_title`, `page_num`,
  `section`, `source_file`, `text_snippet`;
- `fragments` и `retrieved_docs` — найденные фрагменты для диагностики;
- `abstained`, `grounding_errors`, `confidence`;
- `reformulated_query` — если режим переформулирует запрос;
- `processing_time`, `retrieval_time`, `answer_time`.

Правила:

1. Пустая выдача — честный отказ **без вызова LLM**, ошибка `no_fragments`.
2. Пустой ответ LLM — отказ с `llm_unavailable_or_empty`.
3. Ответ без валидных `[n]` заменяется отказом (общий контракт H2-6).
4. `confidence` — качество заземления, а не вероятность правильности:
   `0.0` — отказ/нет цитат, `0.5` — есть ошибки, `1.0` — чистое заземление.
5. Неизвестный режим — `400`; неинициализированная система — `500`.

## 5. Обратная связь, история и экспорт

- **Обратная связь:** кнопки «полезно / бесполезно» и необязательный
  комментарий; `POST /api/feedback` пишет одну строку в JSONL.
- **Формат записи:** `schema_version: 1`, UUID, UTC-время, вопрос, ответ,
  режим, оценка, комментарий, цитаты. IP, user-agent и ID пользователя
  **не сохраняются**.
- **Путь:** `outputs/feedback/feedback.jsonl` (каталог в `.gitignore`);
  переопределяется `FEEDBACK_PATH`.
- **История:** хранится только в браузере (`localStorage`,
  `hipporag.history.v1`, до 50 записей). Сервер историю не хранит.
- **Экспорт:** текущий ответ — Markdown/JSON; вся история — Markdown/JSON.
  Экспорт выполняется на клиенте, без дополнительных запросов.

## 6. Аутентификация

Статика UI публична, чтобы страница открылась до ввода ключа. Все данные
закрыты тем же guard, что и раньше:

- публично: `/`, `/ui`, `/ui/*` (HTML/CSS/JS и список режимов);
- под ключом: `/api/ask`, `/api/feedback`, `/search`, `/health`.

Ключ вводится в диалоге и хранится в `sessionStorage` только на время
вкладки. `API_KEY_REQUIRED=1` по умолчанию: без `API_KEY` сервер не стартует.
Для локальной разработки на loopback разрешён явный opt-out
`API_KEY_REQUIRED=0`.

## 7. Как запустить

```powershell
$env:PYTHONIOENCODING = "utf-8"
$env:API_KEY = "your-secret-key"
uvicorn astro_app.web:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/` и введите ключ. Для локального запуска без
ключа:

```powershell
$env:API_KEY_REQUIRED = "0"
uvicorn astro_app.web:app --host 127.0.0.1 --port 8000
```

Нужны тот же индекс (`SAVE_DIR`, по умолчанию `outputs/astrology_test`) и
LM Studio, что и для CLI. Без индекса страница откроется, но `/api/ask`
вернёт пустую выдачу и честный отказ.

- **Обратная связь только пишется.** Просмотра и выгрузки через UI пока нет —
  файл читается вручную.
- **Page-level режим 5 не подключён** до замера H1-6.
- **Нет Docker/one-command start** — это H2-3; нет жизненного цикла данных —
  H2-2; нет структурных метрик — H2-4.
