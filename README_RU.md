# HippoRAG — Поиск по астрологическим PDF

Система поиска по книгам по астрофэншуй с 23 методами поиска, графом знаний, sentence-level индексацией, DAT (динамический альфа) и кэшем ответов.

## Быстрый старт

Полная инструкция — [docs/HOW_TO_RUN.md](docs/HOW_TO_RUN.md).
План развития проекта — [docs/ROADMAP_REVISION_DEEPSEEK.md](docs/ROADMAP_REVISION_DEEPSEEK.md) (v1.2, горизонты H0 → H3).

```bash
python -m pip install -e ".[dev]"
python main.py
```

При запуске выберите модель, затем метод поиска и введите запрос.

## Режим по умолчанию и рекомендация

**По умолчанию — режим 2 «Граф» (entity linking + PPR).** В меню он помечен
«(по умолчанию)», и пустой ввод в строке выбора режима подставляет именно его.
Рекомендованы два режима (⭐ в меню):

| Режим | Когда выбирать | Почему |
|---|---|---|
| **2 «Граф»** ⭐ (по умолчанию) | обычный поиск по корпусу | recall@5 95,0 % на 40 размеченных вопросах, p50 545 мс, LLM не нужен |
| **1 «Multi-vector»** ⭐ | нужна максимальная точность | recall@5 97,5 % (лучший измеренный), но p95 12,8 с и нужен LLM |

Остальные 21 режим — экспертные: у каждого в меню указано, когда он уместен.
Режимы 12 «Self-RAG» и 19 «GraphRAG» помечены ⏱ — по замерам их p95 больше
30 с, поэтому они помечены как экспериментальные и по умолчанию выключены.

Бюджеты латентности, методика замера и то, что осталось измерить, —
в [docs/PERFORMANCE.md](docs/PERFORMANCE.md). Основание выбора и его разбор —
в [docs/MAVIS_ROUND3_REMARKS.md](docs/MAVIS_ROUND3_REMARKS.md) §7.3.

## Возможности

- **23 метода поиска** — от BM25 до DAT Sentence-level + LLM
- **Рекомендация режимов** — два рекомендованных и режим по умолчанию, выбранные по замерам
- **4 модели LLM** на выбор при запуске
- **Sentence-level chunking** — поиск по предложениям (число зависит от корпуса)
- **DAT (Dynamic Alpha Tuning)** — LLM оценивает два метода поиска и динамически подбирает вес
- **Pattern Search** — точный поиск конструкций «ЗНАК — ЗОНА» (0.3с, без LLM)
- **QA Cache** — автоматическое кэширование ответов, тестирование методов, экспорт для обучения
- **Полностью на CPU** — ни один метод не требует CUDA
- **Русскоязычная доменная область** — астрология, фэншуй, знаки зодиака, планеты, зоны квартиры

## Методы

⭐ — рекомендованный · ⏱ — экспериментальный (p95 > 30 с, по умолчанию выключен)

| # | Название | Описание | LLM |
|---|---|---|---|
| 1 | Multi-vector + LLM ⭐ | Переформулировка запроса через LLM, мульти-векторный поиск | Да |
| 2 | Графовый PPR ⭐ (по умолчанию) | Entity linking + Personalized PageRank на графе знаний | Нет |
| 3-4 | BM25/Small-to-big + CE-en | Английский cross-encoder | CE |
| 5-6 | BM25/Small-to-big + RU-CE | Русский cross-encoder DiTy | CE |
| 7 | HyDE | LLM генерирует гипотетический документ | Да |
| 8 | Фильтр + RU-CE | Поиск только в разделе нужного знака | Нет |
| 9-11 | Весь знак | Полный текст/DOCX + LLM резюме/обработка | Да |
| 12 | Self-RAG ⏱ | BM25 → LLM формулирует ответ | Да |
| 13 | RRF + контекст | Ранжирование через Reciprocal Rank Fusion | Нет |
| 14 | E5 sentence-rerank | Мультиязычный E5 для переранжирования | Нет |
| 15 | RRF + sign | RRF + приоритет знака зодиака | Нет |
| 16 | ColBERT-v2 | Late interaction между токенами | Нет |
| 17 | LLM-фильтр | Фильтрация результатов через LLM | Да |
| 18 | Qwen3 + FRIDA | Qwen3 + FRIDA + BM25 | Да |
| 19 | GraphRAG Agent ⏱ | Маршрутизация + самокоррекция | Да |
| 20 | Sentence-level | BM25 по предложениям, группировка по чанкам | Нет |
| 21 | DAT + LLM | Sentence + Dense → LLM → динамический α | Да/fallback |
| 22 | Pattern Search | Точный поиск «ЗНАК — ЗОНА», приоритет классификаций | **Нет** |
| 23 | QA Cache | Кэш готовых ответов, автосохранение | Нет |

## QA Cache

- Автосохранение: каждый ответ → `outputs/qa_cache/qa_cache.json`
- Метод 23: повторный вопрос → ответ из кэша (0.1с)
- `t` в меню — тестирование всех методов, сравнение с кэшем
- `e` в меню — экспорт в JSONL для fine-tuning
